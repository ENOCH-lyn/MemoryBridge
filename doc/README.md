## 后续拆分计划

进入实现阶段后，按 itime 的文档分类补齐：

- `doc/设计/`：记忆生命周期、同步协议、检索排序、经验晋升、权限模型。
- `doc/测试/`：CrossProjectBench、检索评测、同步收敛、安全测试。
- `doc/验收/`：每阶段真实执行结果与证据。
- `doc/运维/`：部署、备份恢复、升级、监控。
